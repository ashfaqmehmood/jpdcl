# Security policy

Report credential handling, OAuth, authorization, privacy, or account-isolation vulnerabilities through [GitHub's private security-advisory form](https://github.com/ashfaqmehmood/jpdcl/security/advisories/new).

Do not put passwords, OAuth tokens, account IDs, consumer numbers, bills, meter readings, or exploit details in a public issue. General non-sensitive bugs can use the public issue tracker.

The hosted plugin is read-only. Reports showing unauthorized account access, credential disclosure, token replay, OAuth redirect abuse, or unintended write capability are treated as high priority.
